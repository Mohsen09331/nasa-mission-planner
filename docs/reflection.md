This lab was about the use of GitHub as an organizer and manager for a software project. I learned about creating issues, labels, assigning tasks, creating different branches, making commits and merging changes with pull requests.
I also learned of the importance of branches since they enable the development of new features in isolation of the main project.
For me, the hardest part was figuring out how the branches, commits and pull requests interacted. Upon using these a few times, the process became easier to understand. 
What was fun, was the process of slowly developing the NASA Mission Planner and the improvements made after each commit!
I would spend more time working on the design of the app and make the mission planner more interactive if I could. 
I would also incorporate additional destinations, mission information, and features to keep the application more useful and interesting.
